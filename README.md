# StockSync

Step 1: Set Up the Environment
First, ensure Python is installed on your system. Then, open a terminal or command prompt and execute the following commands to install the necessary dependencies:

pip install flask
pip install reportlab
Tip: You don’t need to install datetime separately — it’s already included with Python.

Step 2: Launch the Application
Use the terminal to move into the folder where your project files are located:

cd path/to/project-folder
To start the application, run:

python app.py
Once the app is running, open your web browser and visit:

http://localhost:5000/
You should now be able to use the application in your browser.
